Privacy policy

Last updated: 25 October 2026

Under the Heatsink uploader is a private tool run by the owner of the Under the Heatsink YouTube channel, for that channel only.

  • It uses Google's YouTube Data API only to upload videos to the owner's own channel.
  • It does not collect, store, sell or share personal data of any other person.
  • The owner's sign-in token is stored only on the owner's own device and is never shared.
  • Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
